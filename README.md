# Calisthenics Project

A full-stack application for calisthenics training and management.

## Project Structure

```
Calisthenics/
├── calisthenics-react-admin/     # React-based admin frontend
├── calisthenics-backend-admin/   # Backend API for admin functionality
├── calisthenics-backend-common/  # Shared backend utilities and code
└── calisthenics-backend-portal/  # Backend API for user portal
```

## Getting Started

### Frontend (React Admin)
```bash
cd calisthenics-react-admin
npm install
npm run dev
```

### Backend Services
Each backend service will have its own setup instructions as they are developed.

## Development

This is a monorepo structure where each directory represents a different service or application component of the Calisthenics platform.
